AGENTIC DEVSECOPS HANDOFF MAP

Flow description: Read the phase spine from top to bottom. An AI agent does the
work in each phase. The branch on the left is what the agent receives, and the
branch on the right is what it hands on. The output of one phase is the input
of the next. [GATE] marks a point where a person approves before the flow
continues. On narrow screens, each phase is followed by its input and output.
A table below the flow lists four changes that agents bring, each with a risk,
a control and the source passage.

INPUT                           PHASE               OUTPUT
-----                           -----               ------
Request and context             o-- 01 Plan    --+ Task spec
                                |                  [GATE] A person approves the spec
Spec and repository             o-- 02 Code    --+ Pull request
                                |
Pull request and threats        o-- 03 Review  --+ Verdict
                                |                  [GATE] A person approves the merge
Approved code                   o-- 04 Build   --+ Signed artifact
                                |
Artifact and environment        o-- 05 Test    --+ Test evidence
                                |
Evidence and policy             o-- 06 Release --+ Go or no go
                                |                  [GATE] A person decides on production
Approved artifact               o-- 07 Deploy  --+ Running service
                                |
Signals                         o-- 08 Operate --+ New work

Incident tickets, patches and new issues from Operate go back to Plan as new
requests.
