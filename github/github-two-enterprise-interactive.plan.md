# Plan: claims verifiable from the popup

2. Write one evidence row per sourced fact: exact quote, source from the box's list.
3. Reword or split sentences that go beyond their source.
4. Show numbered markers, an Evidence list and a legend in each popup.
5. Check quotes mechanically with `verify-evidence.mjs` before any date moves.
6. Cover the design-choice notes, checks, chips and summaries: source them, reword them, or mark them.
7. Test every filter, every highlighted box and every popup link, in light, dark and 375px.
8. Keep the fact check, decisions and the index date in step.
