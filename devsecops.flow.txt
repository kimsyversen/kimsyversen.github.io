DEVSECOPS LIFECYCLE MAP, TWO VIEWS

Flow description: A switch at the top selects one of two views. Each view is a
row of numbered phase boxes. Selecting a box shows the detail of that phase
below the row. A table under the boxes lists risks with their evidence.
Boxes with an accent border mark a checkpoint (DevSecOps) or a human gate
(Agentic). Work from the last phase returns to Plan.

VIEW 1: DEVSECOPS (ten phases, two rows of five)
Detail panel: governance activity, secure development activity, risk count.
Table: governance and secure development risks by phase.

[01 Plan *] -> [02 Design *] -> [03 Code *] -> [04 Build] -> [05 Test]
[06 Release *] -> [07 Deploy] -> [08 Operate *] -> [09 Monitor] -> [10 Retire]
* checkpoint

Monitoring, incidents, changes and new vulnerabilities can return work to Plan.

VIEW 2: AGENTIC DEVSECOPS (ten phases, two rows of five)
Detail panel: input, output, human gate, risks.
Table: four changes agents bring, each with a risk and a control.

[01 Plan G] -> [02 Code] -> [03 Review G] -> [04 Build] -> [05 Test]
[06 Release G] -> [07 Deploy] -> [08 Operate] -> [09 Monitor] -> [10 Retire G]
G human gate. The output of one phase is the input of the next.

Monitor sends alerts to Operate. Incident tickets and new issues from Monitor go
back to Plan as new requests. Retire starts from a decision to retire and ends
the flow.

On narrow screens the boxes stack in one column.
