DEVSECOPS LIFECYCLE MAP

Flow description: Read the phase spine from top to bottom. A branch on the left
joins each phase to its governance activity, and a branch on the right joins it
to its secure development activity. Diamond markers indicate governance checkpoints.
On narrow screens, each phase is followed by its two labeled activities.
A risk table below the process groups governance and secure development
risks by phase. Each risk expands to a standard and a documented case
or statistic. Blank cells have no documented case.

GOVERNANCE ACTIVITIES           DELIVERY PHASE       SECURE DEVELOPMENT ACTIVITIES
---------------------           --------------       -----------------------------
Classify                        o-- 01 Plan    --+ Security requirements
                                |
Choose concept                  o-- 02 Design  --+ Threat modeling
                                |
Ready to build                  o-- 03 Code    --+ Secure coding and review
                                |
Track evidence                  o-- 04 Build   --+ Build traceability
                                |
Review test evidence            o-- 05 Test    --+ Security testing
                                |
Production go / no-go           o-- 06 Release --+ Release verification
                                |
Controlled promotion            o-- 07 Deploy  --+ Rollout and rollback
                                |
Handover                        o-- 08 Operate --+ Service maintenance
                                |
Measure and improve             o-- 09 Monitor --+ Detection and alerting
                                |
Closeout                        o-- 10 Retire  --+ Secure decommissioning

Monitoring, incidents, changes and new vulnerabilities can return work to Plan.
