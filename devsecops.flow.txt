DEVSECOPS LIFECYCLE MAP, TWO VIEWS

The view switch selects a set of numbered phase cards. The selected card is
ivory. On desktop, a return across the gap between rows connects Test to
Release. Solid connectors highlight the selected phase's neighbours. A dashed
connector runs from the selection to Plan, since feedback can arise at any
phase. Narrow screens use a compact two-column phase index.

VIEW 1: DEVSECOPS

[01 Plan *] -> [02 Design *] -> [03 Code *] -> [04 Build] -> [05 Test]
                                                                   |
            +------------------------------------------------------+
            v
[06 Release *] -> [07 Deploy] -> [08 Operate *] -> [09 Monitor]
[10 Retire] closes the lifecycle.

* Governance checkpoint. The panel shows governance and secure development
activities and links to the selected phase's risks and evidence.

VIEW 2: AGENTIC DEVSECOPS

[01 Plan G] -> [02 Code] -> [03 Review G] -> [04 Build] -> [05 Test]
                                                                  |
            +------------------ Test evidence --------------------+
            v
[06 Release G] -> [07 Deploy] -> [08 Operate] -> [09 Monitor]
[10 Retire G] starts from a decision to retire and ends the flow.

G Recommended human gate. The selected trace names the handoffs and any human
approval. The phase panel gives the inputs and outputs. Earlier outputs and
standing inputs can also supply a phase.

Release receives test results and a risk verdict. A person decides whether to
approve production. On approval, Deploy receives the approved artifact.
Monitor sends alerts to Operate and incident tickets and new issues to Plan.

The worked example follows one bug fix. The phase register holds the risks and
evidence. The theme index links into that register.

PRESENTATION

Slide 1: [Plan]
Slide 2: [Plan] -> [Design or Code]
Slide 3: [Plan] -> [Design or Code] -> [Code or Review]

Each slide adds one phase from the selected view's order above and marks the new
phase as current. The diagram wraps on narrower screens. It shows the lesson
order. Retirement starts from a separate decision to close the service.
