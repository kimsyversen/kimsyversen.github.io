Search method (2026-11-12): the CISA KEV file filtered for MCP and LiteLLM; NVD keyword search "Model Context Protocol" (164 hits) and "MCP server" (525 hits), the hits whose description names Microsoft, Azure, GitHub, Copilot or similar were read by description, not by following each reference; web searches for exploited MCP flaws, Asana, Supabase, GitHub MCP, tool poisoning and malicious packages. Read in a second pass over all saved NVD hits that mention MCP and a Microsoft, Azure, GitHub or Copilot term (38 records): the two above were added. Not mapped, no matching threat row or outside the architecture: CVE-2026-27124 FastMCP and CVE-2025-4143 workers-oauth-provider (OAuth consent and redirect checks), the three MCP Registry CVEs (CVE-2026-44428, -44429, -45781), CVE-2026-31945 LibreChat, CVE-2026-1721, CVE-2026-39974 n8n-MCP, CVE-2026-49856, CVE-2026-93982 OpenPanel, Cursor CVE-2025-64109 and -61590. Fourth pass: GitHub advisory database, reviewed advisories for the MCP ecosystem 2025-01-01 to 2026-11-12 (the API returned 16 unique advisories, all SDK libraries); three matched failure types and were added, the rest (Ruby SDK memory and session issues, Python SDK denial of service, redirects and $ref fetching on the client) fit no existing failure type or only denial of service of a library and were not mapped. Third pass (web search for exploited and Microsoft MCP advisories) found the two records CVE-2026-109492 and CVE-2026-33032 above. Seen and not mapped: CVE-2026-120792 Aspire CLI log exposure (not part of this architecture), Trend Micro ZDI-CAN-28042 Azure MCP Server (no CVE found), MCPwnfluence mcp-atlassian exploit on a forum (report only, no primary source read), Microsoft's tool-poisoning guidance (no vulnerability). Also not mapped: CVE-2026-47427 GitHub MCP Server crash (no matching threat row; a crash before sign-in would fit F-D or D5 but has no new failure type worth a row); the many MCPHub CVEs (a different product).
Seen only as demos or vendor blogs, so not added: Supabase MCP prompt injection (General Analysis, 2025-07), tool-poisoning demos. No confirmed in-the-wild tool-poisoning attack was found.

Left out as unconfirmed: CVE-2026-54052 (one blog claims KEV, not in the KEV file I read), CVE-2026-42208 (LiteLLM SQL injection, KEV, no MCP element), ZDI-26-226 (seen only on aggregator sites), vendor-only download figures.

Left out, with reason: Langflow, n8n, Flowise code execution (CVE-2025-3248, 34291, 59528, 68613, 21858, 0768, 0770, 33017, 55255, 9198), Ray, LMDeploy, PraisonAI, MLflow, Cursor file protection and sandbox (CVE-2025-59944, 2026-50548), Codex CLI metadata (2026-19592) are general AI tools with no stated MCP step; gemini-mcp-tool, github-kanban-mcp-server, node-code-sandbox-mcp, create-mcp-server-stdio and mcp-server-git CVE-2025-68145 (CVE-2026-0755, 0756, 2025-53372, 54994, 68145), MCPJam inspector (2026-23744) and MCP TypeScript SDK CVE-2026-104850 are real MCP flaws of a type already shown by a listed record in the same row (command injection, path limits, local server), so adding them would repeat a row without a new finding.
