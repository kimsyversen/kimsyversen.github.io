# MCP Server Intake Process v3 decisions

Recorded 27 November 2026.

- **Keep the reader-facing process to five steps.** Keep detailed evidence collection and testing in the separate security assessment methodology and checklist so requesters can follow the process and assessors can use repeatable checks.
- **Use three capability-based risk levels and approval authorities as proposed defaults.** Adapt them to the organization's existing governance. Do not add numerical scores, complex RACI matrices or extra tiers initially.
- **Treat the mandatory controls as the minimum production checklist.** Add platform-specific controls where needed.
- **Treat the scanning applicability matrix as a proposed baseline.** Validate it against available tools and deployment environments. Scanner coverage for the listed checks has not been independently benchmarked.
